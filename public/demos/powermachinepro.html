How It Works

FROM SCAN TO
DASHBOARD

01
Member scans fingerprint at entrance
The BioEntry W3 device reads the fingerprint and fires an event to our middleware server in under 1 second.
02
System checks membership status
If active — door opens, attendance logged. If expired — door stays locked, alert sent to member and admin.
03
Admin dashboard updates live
Via WebSocket, the admin sees the member go green on the live check-in board — no page refresh needed.
04
Member gets a session notification
"Welcome Rohit! Enjoy your session." On exit, duration is calculated and added to their history.
